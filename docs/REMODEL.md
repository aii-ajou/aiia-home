# AIIA 홈페이지 개편 (2026-09)

## 디자인과 정보 구조

아주대학교 [UI 가이드](https://www.ajou.ac.kr/kr/intro/uibasic01.do)의 블루 중심 정체성을 유지하고, 따뜻한 흰색·중립색 배경과 넉넉한 여백으로 정리했다. 강한 다색 강조·장식·큰 통계 숫자를 없애고 연구원의 목적과 연구 분야를 먼저 소개한다. 기본은 밝은 화면이며 상단 메뉴 오른쪽의 화면 모드 버튼으로 어두운 화면을 선택할 수 있다. 모바일에서도 메뉴를 열지 않고 사용할 수 있으며 선택은 브라우저에 저장한다.

- 홈: 소개 → 연구 분야 → 소식 3건 → 연구자 5명 → 펼쳐 보는 조직 정보 → 협력 문의 → 위치.
- `/members/`: 이름·영문명·소속·연구 분야 검색, 소속 필터, 10명씩 페이지 이동. 각 연구자 프로필에서 전체 연구 분야와 연락처 제공.
- `/news/`: 제목·요약·출처 검색, 분류 필터, 9건씩 페이지 이동. 최신 날짜 우선, 추천 소식이 맨 위.
- 사진이 없거나 로드에 실패하면 연구자 이름 또는 소식 분류가 보인다. JavaScript가 없어도 전체 목록과 상세 링크를 사용할 수 있다.
- 제출 기능이 없던 문의 폼은 실제 이메일 작성으로 연결한다. 사이트 자체에서 문의를 저장하거나 발송하지 않는다.

## 콘텐츠 편집·배포

운영 콘텐츠는 별도 비공개 `aii-ajou/aiia-content` 저장소로 분리했다. `/admin/`에서 Pages CMS 편집 화면으로 이동한다. 개발자는 샘플로 실행하며 필요한 경우에만 운영 콘텐츠를 별도로 가져온다.

설정·편집자 초대·저장·배포 방법은 [운영 안내](OPERATIONS.md), 개발 절차는 [README](../README.md)를 따른다. 이전 Decap CMS와 OAuth 릴레이는 사용하지 않는다.

## 사진 출처

공식 페이지에서 이름·이메일이 일치하는 사진만 사용하고 WebP로 저장했다. 각 교수의 JSON `photo_source`, `profile_url`에 원문 주소를 기록했다. 확인하지 못한 사진은 관리자 사진 점검 목록에서 추가할 수 있다.

- [아주대학교 공식 홈페이지](https://www.ajou.ac.kr/kr/index.do): 캠퍼스 사진 (`/_res/ajou/kr/img/main/main_news_thumbnail02.png`).
- [제3회 AI융합 워크숍](https://www.ajou.ac.kr/kr/ajou/news.do?mode=view&articleNo=370653): 소식 사진.
- [소프트웨어학과 교수진](https://software.ajou.ac.kr/bbs/board.php?tbl=professor): 교수 프로필 사진 및 연구 분야.
- [디지털미디어학과 교수진](https://www.ajou.ac.kr/media/people/faculty.do), [금융공학 교수진](https://www.ajou.ac.kr/biz-e/faculty/financial.do): 추가 교수 사진.
- 개원식 사진과 기존 소식 원문 주소는 저장소의 기존 자료를 유지했다.

## 글꼴과 여백 기준

공개 페이지의 크기는 `src/styles/aiia-tokens.css`에서 관리하고 `global.css`의 공통 클래스를 사용한다. 개별 컴포넌트에서 모바일 제목 크기를 다시 덮어쓰지 않는다.

| 용도                     | 공통 클래스/토큰                   | PC   | 모바일 (560px 이하) |
| ------------------------ | ---------------------------------- | ---- | ------------------- |
| 슬로건·섹션·페이지 제목  | `.text-heading`, `.section__title` | 32px | 26px                |
| 분야·가치·카드 제목      | `.text-subheading`                 | 19px | 19px                |
| 본문·소개                | `.text-body`, `.section__lede`     | 17px | 16px                |
| 메뉴·버튼·입력           | `--aiia-text-control`              | 16px | 16px                |
| 보조 설명                | `.text-small`                      | 14px | 14px                |
| 사진 설명·영문 표기·날짜 | `.text-caption`                    | 12px | 12px                |

제목은 Noto Sans KR 500으로 통일한다. 로고·사진 대체 이니셜·아이콘의 크기는 별도로 유지한다. 기본 섹션 상하 여백은 PC 64px, 태블릿 48px, 모바일 40px이다. 버튼은 공통 안쪽 여백 8px × 14px를 쓰고 모바일에서는 최소 높이 44px를 확보한다. 상단의 `header-actions`는 협력 문의·화면 모드와 향후 언어 선택을 함께 배치할 영역이다.
